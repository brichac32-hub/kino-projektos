# Zdroje a vizuální podklady

- **Struktura a wireframy:** uživatelem dodaný dokument `Kino_ClientSite.pdf`.
- **Srovnání rozsahu:** studentský web FaremSpolu, https://ete32e.pef.czu.cz/zs2526/15/FaremSpolu_final/landing.html. Slouží jako měřítko prezentační části a dialogového přihlášení; zdrojový kód webu nebyl převzat.
- **Texty, fiktivní filmy, rozložení a SVG značka:** vytvořené pro tento projekt. Nejde o skutečné filmové plakáty ani reálný program kina.
- **Vizuální inspirace:** https://cinestar.cz/ a https://www.cinemacity.cz/ — využité jako reference pro výrazný filmový banner, práci s plakáty, tmavou paletu a jasné akce pro nákup vstupenek. Původní wireframy určují rozložení projektu; kód a značky těchto kin nejsou převzaté.
- **Písmo běžných textů a navigace:** Roboto (Google Fonts), https://fonts.google.com/specimen/Roboto. Lokální soubory `assets/roboto-regular.ttf`, `assets/roboto-semibold.ttf` a `assets/roboto-bold.ttf`; licence SIL Open Font License je přiložená v `assets/Roboto-OFL.txt`.
- **Písmo nadpisů:** Saira Semi Condensed Bold (Google Fonts), https://fonts.google.com/specimen/Saira+Semi+Condensed. Lokální soubor `assets/saira-semi-condensed-bold.ttf`; licence SIL Open Font License je přiložená v `assets/Saira-OFL.txt`.
- **Fotografie:** Unsplash, stažené lokální ilustrační fotografie. Podmínky použití: https://unsplash.com/license.
